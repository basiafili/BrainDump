# Shared Visual Reference

This file is a reference, not an alternative set of requirements. Editor Window, Accessibility, and Decisions define the binding behavior.

## SF Symbols

| Action | Symbol |
| --- | --- |
| New Capture | `square.and.pencil` |
| New Project | `folder.badge.plus` |
| Open Project | `folder` |
| Save | `square.and.arrow.down` |
| Cut | `scissors` |
| Copy | `doc.on.doc` |
| Paste | `clipboard` |
| Change Folder | `folder` |
| Reveal in Finder | `magnifyingglass` |
| Remove Project | `trash` |

No icon is required for Cancel, OK, Create, Open, the project switcher's displayed value, or main-menu items. Symbols supplement visible text; accessible names match action labels.

## Typography

System fonts for controls and Help; a readable system monospaced font for the editor. Respect system text-size settings where practical. Roboto and Roboto Mono are not product requirements.

## Menu group labels

Use meaningful localized labels such as “Projects A–D”, “Projects starting with A”, and “Other projects…”. Project entries themselves always show their full registered names.
